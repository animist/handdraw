# Air Draw v3（プロトタイプ）

カメラ映像から手を認識して、空中に絵を描くアプリです。
**手を自然にしている間はカーソル移動だけ**で、決めた形にしたときだけ描きます。
MediaPipe Gesture Recognizer（`@mediapipe/tasks-vision` 1.0.1）と WebGL2 を使い、ブラウザだけで動きます。

| ファイル | 内容 |
|---|---|
| `index.html` | v3 本体（UI・手の認識・ストローク管理） |
| `glow.js` | 光の筆レンダラー（WebGL2：フィードバック描画、流体、ブルーム） |
| `sfx.js` | 効果音（Web Audio） |
| `v2.html` / `v1.html` | 旧バージョン（比較用、単体で動作） |

## 起動方法

カメラは **https か localhost** でしか使えません。また v3 は複数ファイルに分かれているので、フォルダごとローカルサーバーで開きます。

```bash
cd fist-draw
python3 -m http.server 8000
# → http://localhost:8000
```

Chrome / Edge を推奨します。音を出すため、「カメラを開始」ボタンを押した時点で音声も有効になります。

## 操作

| 方式（右パネル「描画の合図」） | カーソル移動だけ | 描く／パレットを選ぶ | 消しゴム |
|---|---|---|---|
| 🤏 ピンチ（既定） | 自然な手 | 親指と人差し指をつまむ | ✊ グー |
| ☝️ 人差し指 | パー・✌️ | 人差し指だけ立てる | ✊ グー |
| ✊ グー | パー | グー | パレットの 🧽 |

- 映像上部の**パレット**：色8色、🌈虹色、消しゴム、太さ S/M/L、戻す、全消去
- ピンチ方式では、カーソルの周りの赤いリングが「あとどれだけ閉じれば描けるか」を示します
- キーボード：Z 戻す（ペンのみ）/ C 全消去 / S PNG 保存

## v3 で追加した表現（すべて右パネルで切り替え・調整できます）

### 1. 光の筆（スタイル：✨ 光の筆）
- 色は**加算合成**で重なり、なぞるほど白く光ります。HDR で蓄積してからトーンマップで表示するので、白飛びせずなめらかに明るくなります
- **ブルーム**（光のにじみ）付きです
- **消えるまで**：1〜30秒。右端にすると ∞（消えない）
- **動き**：
  - 滲むだけ：その場でにじみながら消えます
  - 流れる（ノイズ）：煙のように渦を巻いて流れます（流れの強さで調整）
  - かき混ぜる（流体）：手の動きで流体をかき混ぜます。「手を開いていてもかき混ぜる」がオンなら、描いていない手でも混ぜられます
- **にじみ / 光の強さ / ブルーム / カメラ映像の明るさ**を調整できます
- 「🖊 ペン（残す）」スタイルに切り替えると、v2 と同じ「残る線」に戻ります（戻すも使えます）

### 2. ピンチの筆圧
- つまむ強さ（親指と人差し指の距離）で、線の**太さと明るさ**が変わります（ピンチの筆圧）
- 速く動かすと細くなります（速さで細く）
- どちらも 0 にすれば一定の太さになります

### 3. 音のフィードバック
- 描き始め・描き終わり・消しゴム・パレット選択で**クリック音**が鳴ります
- 描画中は、**高さ＝画面の上下、音量＝速さ、音色の明るさ＝筆圧**の音が鳴ります。「音階に合わせる」でペンタトニックに量子化します
- 消しゴムは擦れるノイズ音です
- 「クリックのみ」「オフ」にもできます

### 4. 万華鏡
- 対称数 2〜12 と、鏡映（左右対称）を組み合わせられます。光の筆・ペンの両方で使えます
- 対称位置に薄いカーソルとガイド線が出ます

## 線が途切れる問題への対策（v2 から継続）

見失っても少し待ってつなぐ（Hermite 補間）、誤判定の吸収、入りは早く抜けは慎重に、追跡の粘り、軽い解像度＋60fps 要求、手動露出。詳しくは右パネル「判定の調整」「カメラ・表示」と、診断表示を参照してください。

## 既知の制約

- 初回はモデル（約 8MB）を CDN からダウンロードします（オンライン環境が必要）
- 光の筆には WebGL2 が必要です。浮動小数点テクスチャ非対応の環境では簡易表示になり、WebGL2 自体が使えない場合はペンスタイルのみになります
- 光の筆は時間で消える前提なので「戻す」は使えません。PNG 保存はその瞬間の画面を保存します
- 手を真横に向けると、ピンチがカメラから見えず判定できません
- 映像はブラウザ内だけで処理され、外部には送信されません
